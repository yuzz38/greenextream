# GreenExtreme

Загрузить папку на HTTPS-хостинг. index.html + отдельные CSS/JS; single-file.html — дополнительная версия со встроенными стилями/JS, внешние медиа остаются в assets. GSAP и Tailwind через CDN; основной CSS работает независимо от Tailwind. Шрифты локальные. Все четыре видео и четыре изображения заказчика включены; две фотографии мастерской дублируются в исходниках и использованы разными кадрированиями.

Для публикации задайте домен через configure-domain.mjs. Цены, отзывы и требования к участникам подтвердить у бренда. Слайдер содержит истории из ТЗ, не выдуманные отзывы. Видео 2 обрезано от чёрных полос. Раздел «Контролируемый занос» объясняет дрифт и использует фотографии из исходного видео. Нет оплаты или фиктивного подтверждения отправки. Встроенный fullscreen может использовать интерфейс ОС на iPhone.
